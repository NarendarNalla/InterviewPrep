# Greedy Algorithms — Learning Roadmap

I'd suggest learning **Greedy Algorithms** in the following order.

---

# Level 1 — Understand the Intuition

Before solving problems, understand **what Greedy is and why it works**.

1. What is Greedy?
2. Greedy vs DP
3. When does Greedy work?
4. How to identify Greedy problems
5. How to prove a Greedy choice

---

# Level 2 — Basic Problems

Start with simple problems to understand the Greedy approach.

1. Activity Selection
2. Assign Cookies
3. Lemonade Change
4. Best Time to Buy and Sell Stock
5. Can Place Flowers

---

# Level 3 — Sorting + Greedy

Learn how **sorting** helps us make the correct Greedy choice.

1. Fractional Knapsack
2. Maximum Units on a Truck
3. Minimum Number of Arrows to Burst Balloons
4. Non-overlapping Intervals
5. Minimum Platforms

---

# Level 4 — Advanced Greedy

Now move to problems where the Greedy decision is less obvious.

1. Jump Game
2. Jump Game II
3. Gas Station
4. Task Scheduler
5. Partition Labels
6. Merge Triplets
7. Huffman Coding

---

# Level 5 — Greedy + Heap

Combine **Greedy + Priority Queue / Heap**.

1. Meeting Rooms
2. Meeting Rooms II
3. IPO
4. Minimum Cost to Connect Sticks
5. Huffman Coding
