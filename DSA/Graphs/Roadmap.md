Recommended Learning Order

Connected Components using adjacency matrix — understand graph traversal.

Number of Islands using DFS — apply the same concept to a grid.

Number of Islands using BFS — replace recursive traversal with a queue.

Number of Islands using a visited array — preserve the input grid.

Number of Islands using DSU — learn the union-find approach.
